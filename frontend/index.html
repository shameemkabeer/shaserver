Pi display

Screen–

Leave a time empty to skip it. Use the daytime break for a second daily window, like a lunch break. When the screen is off, tap it to turn it on. The panel has no backlight control, so brightness dims the picture. Turning the screen off switches off the HDMI signal.

Screensaver

The background is a generated sky that follows the real sunrise and sunset for your location, with the weather under the clock.

To use your own wallpapers, put images in ~/piboard/screensaver/. They change with the time of day. Put sunrise, day, sunset or night in a file name to show it at that time.

Devices

Every browser signed in to PiBoard. The Pi display is the server's own screen and always stays signed in.

Kiosk

The kiosk session is read-only by default.

Change password

Changing the password signs out all other devices. The Pi display stays signed in.
